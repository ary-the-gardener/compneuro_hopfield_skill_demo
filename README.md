# Skill Demonstration: (_"Input-driven dynamics for robust memory retrieval in Hopfield networks"_)[https://doi.org/10.1126/sciadv.adu6991] (Betteti _et al._, 2025)  
Team 8: Aryana Ramos-Vazquez, Ivan-Alexander Kroumov, and Bohan Chen

**Summary:** This paper proposes revolutionizing the Hopfield model by allowing external input (not just initial state) to impact the behavior and memory retrieval of the model itself. The primary consideration or impetus for creating the modified IDP model is that the human brain constantly processes information and current sensory processing alters how the brain may behave; essentially, rather than simply providing a memory or corrupted memory as the initial input to find the energy minimums, the IDP attempts to solve the problem of biological applicability by introducing saliency weights and allowing for external input to redefine the internal energy function, and therefore, at what minima the model falls into (stability of the memory). This model can: (1) emphasize memories relevant to the current input, (2) suppress competing memories, (3) classify ambiguous inputs, (4) retain useful information from previous states, (5) resist brief input glitches. The additional **why** of this paper is to influence development of other technology, such as transformers for neuromorphic computing.
